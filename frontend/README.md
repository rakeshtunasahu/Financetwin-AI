# FinanceTwin AI Frontend Workspace

A professional executive operations dashboard for risk-aware autonomous settlement reconciliation, built using React 18, TypeScript, Vite, Tailwind CSS, Recharts, and Lucide icons.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Set Up Environment Variables
Create a `.env` file or rely on `.env.example`:
```env
VITE_API_BASE_URL=http://localhost:8000
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build Production Bundle
```bash
npm run build
```

## Features

- **Executive Operations Dashboard**: KPI cards for matched counts, safety precision, false match rates, and capital at risk.
- **Reconciliation Workspace**: Multi-pass engine decision explanation drawer featuring weighted fuzzymatch scoring breakdowns.
- **Exceptions Command Center**: Real-time incident logs paired with side-by-side evidence details.
- **Grounded AI Investigator**: Case diagnostic analyzer returning schema-validated explanation narratives.
- **Governance Safety Lab**: Interactive simulation of matching confidence bounds, amount tolerances, and tax variations.
